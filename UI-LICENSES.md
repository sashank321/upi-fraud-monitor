# UI sources

[React Bits Spotlight Card](https://www.reactbits.dev/components/spotlight-card) and [Gradient Text](https://www.reactbits.dev/text-animations/gradient-text) are bundled into the React application. Their upstream license is included in [web/react-bits/LICENSE.md](web/react-bits/LICENSE.md).

- [daisyUI Modal](https://daisyui.com/components/modal/) supplies the native dialog and backdrop pattern. [daisyUI Stat](https://daisyui.com/components/stat/) supplies the figure, title and value structure for the bank summary.
- [shadcn/ui Tabs](https://ui.shadcn.com/docs/components/tabs) supplies the segmented filter presentation. [shadcn/ui Command](https://ui.shadcn.com/docs/components/command) informs the grouped account picker and keyboard shortcut.
- [Open Props gradients](https://raw.githubusercontent.com/argyleink/open-props/main/src/props.gradients.css) supplies gradient 2 and gradient 22.
- [Stripe Radar reviews](https://docs.stripe.com/radar/transaction-reviews) informs the searchable queue, selected payment details and risk evidence placement.
